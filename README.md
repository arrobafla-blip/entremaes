# Entre Mães — versão 2

Site institucional estático e responsivo para o projeto Entre Mães.

## O que está incluído
- Identidade visual cereja, marrom e off-white.
- Apresentação da comunidade e experiências.
- Mapa esquemático ilustrativo das regiões iniciais sugeridas.
- Agenda demonstrativa com filtros por tipo de experiência.
- Área de indicações com categorias e busca.
- Seção de parcerias.
- Modal visual de login/criação de conta.
- Menu adaptado para dispositivos móveis.

## Arquivos
- `index.html`: conteúdo e estrutura.
- `style.css`: identidade visual e responsividade.
- `script.js`: menu, filtros de agenda, busca de indicações e modal demonstrativo.

## Visualizar
Abra `index.html` no navegador. Fotografias e fontes são carregadas de serviços externos e precisam de conexão com a internet.

## Publicar no GitHub Pages
1. Crie um repositório chamado `entre-maes`.
2. Envie `index.html`, `style.css`, `script.js` e este README para a raiz do repositório.
3. Acesse **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`, depois salve.
6. Aguarde o endereço do GitHub Pages ficar disponível.

## Importante antes de divulgar
- Os links do Instagram são provisórios (`https://www.instagram.com/`). Troque pelo perfil oficial do Entre Mães.
- A agenda mostra ideias, não eventos confirmados. Atualize datas, locais, valores e links quando houver programação.
- As indicações são espaços reservados para futuras recomendações. Adicione apenas lugares/serviços verificados e deixe claro quando uma indicação for patrocinada.
- O mapa é esquemático e ilustrativo, não cartográfico. Os bairros listados são uma sugestão de cobertura, não limites oficiais.
- As fotografias são referências visuais hospedadas externamente. Revise direitos, disponibilidade e coerência da seleção antes de publicar.
- O modal de login/cadastro é apenas interface demonstrativa. Não cria contas, não autentica pessoas e não envia nem armazena dados.

## Como ativar login e contas reais
Um site estático hospedado no GitHub Pages não deve guardar senhas nem criar autenticação real apenas com HTML/JavaScript. Para ativar contas, será necessário configurar um provedor de autenticação e banco de dados (por exemplo, Supabase ou Firebase), definir quais dados serão armazenados, regras de acesso e política de privacidade. Não coloque chaves secretas no código público. A configuração precisa ser feita antes de habilitar cadastro real.
